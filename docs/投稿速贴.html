② 一句话简介→ 表单「简介」栏
一个 HTML 文件的离线打字练习场：中文拼音、英文四六级/牛津、唐诗宋词，六种模式，成绩统计，装进 PWA 离线也能练
③ 作品介绍→ 表单「介绍」正文，整段粘贴
它解决什么问题 想练打字的人，打开市面上大多数打字工具，迎面而来的是广告、登录墙、联网加载和不对路的词库——练中文的要四六级和唐诗宋词，练英文的要能看音标释义，最好还能知道自己有没有进步。 简练快打（TypeLab）的做法是：全部装进一个 HTML 文件里，双击打开就能练，不联网、不登录、不装任何东西，所有数据只存在本机浏览器。 功能一览 · 三大练习标签：中文（拼音/汉字双输入）、英文（CET-4 1027 词 / CET-6 / 牛津核心 3000 / 四六级长句，单词带音标与释义，双击句中单词即可查词）、诗词（唐诗宋词 72 首，跟打 / 默写 / 听写） · 六种模式：看打、中→英、看英写拼音、听写、跟打、默写 · 成绩系统：每打完一组自动记录；成绩弹窗含汇总、最近 40 组速度/正确率曲线、CSV 导出、一键生成成绩分享卡片 · 错题本：打错、跳过、看答案自动收录，按错误次数 1~5 次加权重复出题 · 体验细节：WebAudio 合成的键盘音效（零音频文件）、深色模式、8 种背景色、字号无级调节、长文打字当前行自动滚入视口、实时速度条 · 工程化：PWA 可安装、离线可用；Electron 桌面壳；CI 冒烟测试 + 模拟打完一整组的集成测试；打 tag 自动构建 Windows 安装包 v2.0 升级内容（本次用 WorkBuddy 完成） 1. 性能：打字渲染重写为「span 池 + 按字符 diff」的增量渲染，每敲一个键的 DOM 操作从 O(n) 降到 O(1)，长句打字不再整段重建 DOM 2. 统计：新增练习历史（每组一条）、成绩弹窗与 SVG 曲线、CSV 导出、Canvas 分享卡片；最佳成绩改为按整组记录 3. 体验：键盘音效、深色模式（跟随系统/手动）、背景色与字号、长文滚动跟随、错题本加权重复 4. PWA：manifest + service worker（离线可用、后台更新），图标由零依赖 Node 脚本生成 5. 质量：冒烟测试扩展到 v2 特性（增量渲染 DOM 复用断言、模拟打完 5 题一组验证历史落库、弹窗渲染），新增 tag 触发的自动发版流水线 技术亮点 · 单文件零依赖：约 1.1 万行词库数据 + 约 1500 行逻辑，全部内联在一个 HTML 文件里，无构建、无框架、无外部请求 · 增量渲染：span 池复用 + 按字符 diff，配合渲染缓存，击键只重画发生变化的字符 · 零资源音效：WebAudio 振荡器实时合成三种按键音，不打包任何音频文件 · 零依赖图标生成：用 Node 手写 PNG 编码器（crc32 + zlib deflate）生成 PWA 全套图标 · 可测试：jsdom 冒烟 + 集成测试 + 23 条边界断言（打错/退格/光标/跳过/看答案/隐藏模式/拼音/速度条采样） 使用说明（30 秒上手） 1. 打开链接即进入练习（默认英文 CET-4 看打） 2. Tab 开始/重开一组，Esc 跳过本题，Alt+P 朗读，双击单词查音标释义 3. 工具栏切换标签（英文/中文/诗词）、词库、模式、每组数量 4. 「成绩」按钮看统计曲线、导出 CSV、生成分享卡片；「设置」里开音效、换背景、调字号 5. 浏览器菜单「安装应用」即可像普通 App 一样离线使用
