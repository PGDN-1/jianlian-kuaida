一个单文件的打字练习网页：`index.html` 一个文件搞定，零依赖、不联网、双击就能用，也可以安装成 PWA 应用。另有 Electron 桌面版外壳（`app/`），可打包成 Windows 安装包。

**在线试玩：<https://pgdn-1.github.io/jianlian-kuaida/>**

An offline, single-file typing trainer for **Chinese pinyin + English**, with CET-4/6 word lists, Oxford 3000 headwords, IPA, parts of speech, 496 bilingual sentences, and 72 classical Chinese poems. No build step, no dependencies, no network — just open `index.html`. Installable as a PWA. An Electron wrapper for a native desktop app lives in `app/`.

## 打开方式

五种都行：

1. **在线网页版**：直接打开 <https://pgdn-1.github.io/jianlian-kuaida/>，什么都不用下（GitHub Pages 托管，数据存在该浏览器的 localStorage）。
2. **安装成 PWA 应用（v2.0 新增）**：用 Chrome / Edge 打开在线网页版，点地址栏右侧的「安装」图标（或菜单 → 将 TypeLab 安装为应用），就能像原生应用一样从开始菜单启动，且完全离线可用。页面在 `file://` 下双击打开时这一套自动不启用，行为与以前完全一致。
3. **桌面版（推荐）**：装 `D:\DS工作站\typing-lab\dist\简练快打-安装版-2.0.0.exe`，或直接用免安装的 `简练快打-便携版-2.0.0.exe`。桌面版是 Electron 外壳，有自己的窗口和图标，数据存在 `D:\DS工作站\typing-lab\app-data`，不会被浏览器清缓存清掉。外壳源码在 `app/`（见 `app/README.md`）。
4. **双击网页版**：直接双击 `index.html`，或用任意浏览器打开（Chrome / Edge / Firefox 均可）。
5. **桌面快捷方式**：`C:\Users\li\Desktop\简练快打.lnk` 指向网页版，双击即用。

网页版不需要服务器、不需要安装任何东西，数据存在浏览器的 localStorage 里。网页版、PWA 和桌面版之间是独立数据，搬家用「词库管理 → 数据备份 → 导出/导入」。

## 三个标签页 · 六种模式

| 标签页 | 模式 | 屏幕上有什么 | 你要做什么 |
| --- | --- | --- | --- |
| **英文** | 看英文打字 | 英文单词 + 右侧音标 | 照着打，下面显示**词性** + 中文释义 |
| | 看中文写英文 | 中文释义 | 凭记忆写出英文单词 |
| | 听英文写词 | 只放读音 | 听发音写出英文单词（右侧音标，下方词性 + 释义） |
| **中文** | 看中文打拼音 | 汉字词语 | 打它的拼音（默认；也可在工具栏切「汉字」） |
| | 看英文写拼音 | 英文大意 | 凭记忆写出拼音 |
| | 听音写拼音 | 只放读音 | 听发音写出拼音 |
| **诗词** | 跟打原文 | 整首诗词 | 照着原文打（工具栏「跟打」可切拼音/汉字） |
| | 听音写拼音 | 只放标题和读音 | 听整首诗的朗读，按音节写出拼音 |
| | 看标题默写 | 标题 + 作者 | 默写正文（汉字），打完自动揭晓原文 |

「英文」标签页的**词库下拉框**里除了四级、六级单词，还有 **牛津核心 3000**、**四级长句** 和 **六级长句** 三个源：选长句就是整句练习，三种模式照样能用——看英文句子跟打（下方给中文翻译）、看中文翻译写整句、听句子写整句。

## 内置内容

- **四级 CET-4**：1027 词（A–Z 核心词 + 扩充词表，自动去重），格式 `word|中文`
- **六级 CET-6**：1045 词（A–Z 核心词 + 扩充词表），格式 `word|中文`
- **牛津核心 3000**：2970 词（[Oxford 3000™](https://www.oxfordlearnersdictionaries.com/wordlist/english/oxford3000/) 官方词表的词头，A1–B2 高频词），格式 `word|中文`；中文释义是这个工具自己写的简短注释，**不是牛津官方释义**（官方释义受版权保护），拿来练打字足够
- **音标与词性**：`LEX` 表共 4126 条（格式 `word|/音标/|词性`），**四级、六级、牛津核心 3000 的全部词条都有 IPA 音标与词性**。四六级词条的音标词性是逐词手写的；牛津词条里凡与四六级重合的沿用前者，其余的音标来自开源音标库 [ipa-dict](https://github.com/open-dict-data/ipa-dict)（MIT，美式优先），词性由 [WordNet 3.1](https://wordnet.princeton.edu/)（Princeton）按义项数取主要词性、功能词（and/because/could 等）再手工补齐。看英文打字时音标在单词右侧、词性在下方释义行首，听写模式把词性并进释义
- **四级长句 / 六级长句**：各 248 句（合计 496 句），`英文句子|中文翻译`；句子按近十年四六级翻译、写作的常见话题（传统文化、高铁与移动支付、电商、环保、教育、老龄化、人工智能、航天、乡村生活、志愿服务等）整理，**不是逐字照抄某一年真题**；要练逐字真题，用「导入词库」把你手上的真题文本贴进来即可。长句跟打时**只在有难度的实词下方用小字标注词性 + 中文**（冠词、介词、代词等基础词和 family、time、take 这类过于常见的高频词不标；实词按四六级词库反查，词形变化会自动还原）
- **常用中文词语**：69 条，含成语，格式 `词|English gloss|带声调拼音`
- **唐诗宋词**：72 首，格式 `标题|作者|朝代|正文|英文大意`；每首另配一份无声调拼音（`POEMS_PY`），所以诗词也能打拼音
- **补充词库 `EXTRA`**：约 215 条，专给「查词/词尾变形」兜底——牛津 3000 之外但长句里会出现的词（market、subway、province、temple、dumpling、panda、carbon、dynasty…）、常用美式拼写（color、behavior、favorite、theater…）、连字符复合词（high-speed、part-time、short-sighted）和地名

词库里重复的条目会在载入时自动去重（所以同一批扩充词可以放心多处粘贴），实际条数以工具栏下拉框显示为准。

## 中文打拼音

中文标签页默认是**打拼音**，不需要中文输入法：

- 题目大字是汉字，你要打的是它的拼音，如「世界」→ `shijie`（音节间的空格可打可不打）
- **不用打声调**：`shì jiè` 打成 `shi jie` 即可；`ü` 打成 `v`（如 `lǜ` → `lv`）
- 拼音用空格分音节显示在汉字下方作提示；判定看最终拼写
- 工具栏「输入」下拉可以切回**汉字**模式（老玩法，需要中文输入法）
- 打拼音请切到**英文输入法**，否则会打出汉字
- **诗词标签页也能打拼音**：「跟打原文」模式在「跟打」下拉里选「拼音」，打的是整首诗的拼音（无声调、`ü` 写 `v`），屏幕下方同时给出汉字原文对照；选「汉字」就还是照着原文打。**「听音写拼音」**同样是打整首诗的拼音，但屏幕上不显示汉字原文，只念读音；**「看标题默写」始终打汉字**，因为默写要考的正是字形

## 加自己的词库

点工具栏的「词库」按钮 → 填词库名称、选分类 → 粘贴文本或选择 `.txt` 文件 → 导入。

格式（一行一条，用竖线 `|` 分隔）：

```
# 英文词库
abandon|放弃；抛弃
ability|能力

# 中文词语（第三段是拼音，可省；省了就退回汉字输入）
世界|world|shì jiè
塞翁失马|a blessing in disguise|sài wēng shī mǎ
自强不息|to strive unceasingly|zì qiáng bù xī

# 诗词（5 段；没有英文大意就只写 4 段）
静夜思|李白|唐|床前明月光，疑是地上霜。举头望明月，低头思故乡。|Moonlight on the floor looks like frost.
```

导入后会自动切到该词库并开始练习；词库会一直保存在本机，可在弹窗里「练这组」或「删除」。

## 错题本

- 每题第一次敲错、跳过（Esc）、看答案，都会记进错题本（同一个词只累计次数）
- 弹窗里能看最近的错题、一键复制、清空
- 「用错题练一组」会把当前分类下的错题拼成临时词库，专门复习；**错得越多的词重复出现次数越多**（按错误次数 1~5 次加权，v2.0 新增）

## 外观设置

点工具栏的「设置」：

- **打字字号**：滑块 75%–180%，也可以点 `A－` / `A＋` 微调；题目大字只按 38% 的比例跟着放大，主要放大的是打字区。
- **背景颜色**：8 个预设（米白 / 纸黄 / 护眼绿 / 淡蓝 / 浅紫 / 石墨 / 墨绿 / 夜蓝），点最后的取色器可以自选任意颜色。
- **外观模式（v2.0 新增）**：`跟随系统` / `浅色` / `深色` 三选一。「跟随系统」会随系统的深浅色设置自动切换；一旦自选背景色，以自选为准。
- **自动反色**：背景亮度低于 52% 时，正文、边框、光标、逐字着色会自动切成深底配色（亮绿=对，亮红=错），不用手动调文字颜色。
- **键盘音效（v2.0 新增）**：击键反馈音（打对 / 打错 / 过题 / 全组完成各有不同的声音），默认关闭，可调音量；用浏览器 WebAudio 合成，不加载任何音频文件。
- 设置存在 `typelab.look` 和 `typelab.sound`，和词库、错题本一样只在本机；点「恢复默认」一键还原字号与背景。

## 玩法说明

- **严格模式**：必须一字不差才能过，打错要退格改对——这样正确率才可信。
- **长文滚动跟随（v2.0 新增）**：长诗词、长句打字时，当前行滚出屏幕后会自动跟着滚动，视线不用离开题目；移动端软键盘弹出时同样保证当前行可见。
- **顺手不卡（v2.0 新增）**：打字时只重画发生变化的那几个字符（增量渲染），长诗跟打也不会一卡一顿；实时速度曲线每 300ms 采样一次。
- 标点、空格不计分：诗词的句号逗号、英文长句里的空格和标点、拼音音节间的空格都不用打，只比文字本身。
- 速度：英文按 **WPM**（正确字符 ÷ 5 ÷ 分钟），中文、拼音和诗词按 **字/分**。
- 每组结束显示题数、速度、正确率，并按标签页记录最好成绩（右上角）。
- 听写模式答对后会停 0.9 秒揭晓原文，看得见原文的模式停 0.36 秒就跳下一题。
- 题目下方那行小字（词性 + 中文翻译 / 英文大意 / 释义）跟随「设置」里的字号一起放大，颜色也比正文浅一档但保持可读。
- **长句逐词注释**：英文长句跟打时，**只在有难度的实词下方**显示一行小字写明词性和中文（如 `traditional` 下方 `adj. 传统的`）；a/the/of/is 这类功能词和 family、time、take 这类过于基础的高频词不标注，避免整句密密麻麻。判定规则：长度 ≥5、不在内置基础词表 `BASIC` 里、且能在四六级词库中查到（词形变化会自动还原）。隐藏答案的模式（看中文写英文、听写）不显示注释，避免泄题。
- **双击查词**：长句跟打时，把鼠标移到任意单词上**双击**（或点右键），会在光标旁边弹出小窗，显示这个单词的音标、词性和完整中文释义——包括那些因为太简单而没在小字里标注的 a/the/family 之类的词。
- **变形词也能查**：`restaurants`、`studied`、`cities`、`knives`、`leaves`、`went`、`took`、`better`、`happier`、`teeth`、`mice` 这类复数、过去式、比较级、不规则变形都能查到，小窗会同时给出**原形**（右侧灰色 `← restaurant`）和释义；一个词有多种可能的原形时（如 `leaves` → `leaf` 叶子 / `leave` 离开）会分两行都列出来。带连字符的词（`high-speed`、`part-time`）和 `Wi-Fi`、`o'clock` 也能查。词库查不到的词（人名、地名等专有名词）会提示「词库暂未收录」。小窗在 12 秒后、切换下一题、滚动页面或按 `Esc` 时自动消失。

## 成绩统计与分享（v2.0 新增）

工具栏多了一个「成绩」按钮：

- **历史成绩**：每打完一组自动记录一条（分类、模式、词库、题数、速度、正确率、用时），最多保留 500 条，只存本机。
- **汇总**：练习组数、总时长、完成题数、总字符、平均速度、平均正确率，可按 英文 / 中文 / 诗词 筛选。
- **曲线**：最近 40 组的速度（实线）+ 正确率（虚线）走势图，一眼看出自己在进步还是波动。
- **导出 CSV**：全部成绩导出成表格（带 BOM，Excel 直接打开不乱码）。
- **分享本组成绩**：把最近一组的成绩画成一张 PNG 卡片（速度、正确率、用时、分类模式、日期），保存后可以发朋友圈或群里。
- 右上角的最佳成绩改为按**整组**记录（不再是单题速度），更可信。

练习过程中，统计数字下方还有一条**实时速度曲线**，每 300ms 采样一次，当前组的快慢变化随时可见。

## 已知限制

- **中文两种输入方式都支持**：默认打拼音（不需要输入法，判定看最终拼写）；工具栏「输入」切成「汉字」则需要中文输入法，拼音上屏过程中的按键不计入正确率。
- **音标/词性已覆盖全部内置词条**（`LEX` 共 4126 条：四级、六级、牛津核心 3000 全在里）。其中四六级的音标词性是逐词手写；牛津独有的约 2090 个词，音标取自开源音标库、词性取自 WordNet 的主要词性（一两个义项都归到该词，多词性词按义项数排序取前一到两个，如 `zero` → `n./adj.`），个别词可能和牛津词典的标注略有出入。长句的逐词注释里，个别专有名词或完全没有收录的词可能没有小字，属正常现象，不影响打字判定。
- **牛津词头取的是官方 Oxford 3000 词表的词条，中文释义是本工具自写的短语**，不是牛津官方释义（官方释义、例句受版权保护，整本《牛津高阶》无法内置）。所以牛津词库适合练拼写，不适合当词典查义项。
- 朗读用的是浏览器自带的 `speechSynthesis`，音质和是否可用取决于系统语音包。Windows 上建议用 Edge；若没声音，去「设置 → 时间和语言 → 语音」装一下中文/英文语音。
- 诗词正文里的异体字若输入法打不出来，可用 `Esc` 跳过。

清空方法：浏览器开发者工具 → Application → Local Storage → 删除对应键，或在弹窗里清空错题本。

界面与交互思路参考了 [Monkeytype](https://github.com/Miodec/monkeytype)（简洁、逐字着色、实时统计）和中文圈的「跟打器」思路（[tygdq](https://github.com/taliove/tygdq)：贴文章照着打、按最终文本判定），并针对中英双语的输入法差异做了取舍。

词表来源：四级、六级词表为自建整理；**牛津核心 3000** 的词头取自 [Oxford 3000™ 官方词表](https://www.oxfordlearnersdictionaries.com/wordlist/english/oxford3000/)（中文释义自写）；牛津独有词的音标取自 [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict)（MIT），词性取自 WordNet 3.1（Princeton）。
